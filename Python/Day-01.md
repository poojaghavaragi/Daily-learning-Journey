## 1. What is Python?

- Data Analysis

## 3. My First Python Program

```python

```

**Output:**

## 4. Important Concepts

- `print()` – Displays output.
- `#` – Used to write comments.
- `" "` – Used to represent text.
- `()` – Parentheses.
- `.py` – Python file extension.
- Syntax – Rules for writing Python programs.

## 5. Comments in Python

```python

```
